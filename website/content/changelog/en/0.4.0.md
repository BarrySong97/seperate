title: Your agents can now run Seperate
---

Claude Code and Codex can now drive Seperate themselves: open other agents in panes next to theirs, hand them work, wait for the answer and close them when they are done, all where you can watch. Sessions started outside Seperate show up within a second, and every session finally has a name you can recognize.

### Agents can open, steer and wait for other agents

![Claude Code and Codex control Seperate through the seperate command](mock:cli-control)

Every terminal in Seperate now has a `seperate` command, and Claude Code and Codex are told about it when they start. Ask Claude to "have Codex fix the failing test and tell me what it changed", and it can:

- open Codex in a new pane next to its own, with the task as its first message (your keyboard focus stays where it is)
- wait until Codex finishes its turn or asks something, and read its answer or its screen
- reply to its questions, press keys to pick an option, and close the session at the end

`seperate list` shows every workspace, project, worktree and session with its state. Agents can also start sessions in an existing worktree or create a new one first. Whenever an agent opens a session or types into one, its pane header says "Opened by …" or "Typed by …" with the time; the line goes away once you type there yourself. Scripts and bots outside Seperate can use it too, through `/Applications/Seperate.app/Contents/MacOS/seperate-cli`. Run `seperate --help` for everything it can do.

### Sessions started elsewhere appear right away

When you start Claude Code or Codex outside Seperate (another terminal, a Feishu bot, the Agent SDK), the session now appears in the sidebar within about a second, instead of up to a minute later. Seperate also checks again whenever you switch back to it.

### Sessions have real names

Sessions now use the title Claude Code gives a conversation, and it stays up to date as the conversation goes on. Codex sessions without a title are named after the first thing you asked. Sessions started from the Agent SDK or a chat bot get proper names too, instead of "Claude session" or "Codex session".

#### Improvements

- New tabs and splits keep the font size you set with ⌘+ / ⌘-
- Sessions you continue somewhere else move back to the top of their worktree

#### Fixes

- A session started in a worktree that had none was hidden inside a collapsed row; new project and worktree rows now open by themselves
- When a project went from one worktree to several, its existing sessions were folded away; they now stay visible
- Sessions started in Seperate kept placeholder names like "Claude Code 6" after a restart; they now show the conversation's title
