title: Close tabs in bulk, run Claude Code without permission prompts
---

This release makes a crowded tab strip easier to clean up, lets Claude Code run without stopping for permission prompts, and fixes Seperate quitting unexpectedly when you clicked a notification or switched workspaces.

### Close tabs in bulk from the tab menu

![Right-click a tab and choose which tabs to close](mock:tab-menu)

Right-click a tab to choose "Close Tab", "Close Other Tabs", "Close Tabs to the Left", "Close Tabs to the Right" or "Close All Tabs"; options with nothing to close are greyed out. When you close several at once and some terminals are still running, Seperate asks once instead of once per tab. Closed Codex and Claude Code sessions can be reopened from the sidebar later.

### Start Claude Code without permission prompts

![The project's "+" menu now has "Claude Code (Skip Permissions)"](mock:skip-permissions)

Everywhere you can start a new session (the "+" menu, the right-click menus of projects, worktrees and terminals, and the command palette `⌘K`), there's now "Claude Code (Skip Permissions)" under Claude Code. It never asks for permission and runs commands and edits files directly, which suits tasks you want to leave to the agent. It applies to that launch only: sessions restored after restarting Seperate ask for permissions again.

#### Fixes

- Seperate sometimes quit unexpectedly when you clicked a system notification, answered an agent's question or switched workspaces; it no longer does
- After clicking a notification for a session in another workspace, keyboard focus sometimes wasn't in that terminal; now you can type as soon as you land there
