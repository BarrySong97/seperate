Seperate is a macOS workbench for coding agents. This release puts Claude Code, Codex and your terminals in one window, organized by project and worktree, and tells you when an agent needs you.

### Run several agents side by side

Two, three and four panes, or a 2×2 grid, switched with `⌃⌘1`–`⌃⌘4`. Drag a tab to another pane or to a pane's edge. Terminals are rendered by Ghostty's engine.

### Inbox: who's waiting for you

When an agent asks for permission, has a question or finishes, it shows up in the inbox (`⌘I`), with a system notification and a Dock badge. One click takes you to that tab.

### Projects, worktrees and past conversations

The sidebar lists projects → worktrees → sessions, and you can create and delete git worktrees right there. Claude Code and Codex conversations stored on your Mac appear under their projects automatically; on first launch you can pick which of your agents' projects to import.

### Double-click to install, update in the app

The DMG holds a single "Install Seperate": double-click it and Seperate goes into Applications. The app is notarized by Apple, so it opens without a security warning. New versions show up in the top bar and install with one click; you can also turn on automatic download and install in the menu.

#### Also included

- Command palette (`⌘K`); Chinese titles can be searched by pinyin initials
- Multiple workspaces, switched with `⌃1`–`⌃9`
- Open the current worktree in your default editor (`⌥⌘O`)
