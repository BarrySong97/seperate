Seperate 是一个给 coding agent 用的 macOS 工作台。这个版本把 Claude Code、Codex 和终端放进同一个窗口，按项目和 worktree 管理，并在 agent 需要你的时候提醒你。

### 并排运行多个 agent

两栏、三栏、四栏和 2×2 布局，用 `⌃⌘1`–`⌃⌘4` 切换。Tab 可以拖到别的栏或者栏的边上。终端由 Ghostty 的引擎渲染。

### 收件箱：谁在等你

agent 要权限、提问或者跑完时，会出现在收件箱（`⌘I`）里，同时有系统通知和 Dock 角标。点一下就跳到那个 Tab。

### 项目、worktree 和以前的对话

侧栏按项目 → worktree → 会话排列，可以直接新建和删除 git worktree。Claude Code 和 Codex 留在本机的对话会自动出现在对应的项目下；第一次打开时可以从 agent 用过的项目里挑选导入。

### 双击安装，应用内更新

DMG 里只有一个“安装 Seperate”，双击就装进“应用程序”。应用经过 Apple 公证，打开时不会有安全警告。之后的新版本会出现在顶栏，点一下就能更新；也可以在菜单里打开自动下载并安装。

#### 也包括

- 命令面板（`⌘K`），中文标题可以用拼音首字母搜
- 多个 Workspace，`⌃1`–`⌃9` 切换
- 用默认编辑器打开当前 worktree（`⌥⌘O`）
