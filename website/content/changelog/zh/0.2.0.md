---

这个版本让 Tab 多了以后更好收拾，可以不被权限确认打断地跑 Claude Code，并修好了点通知、切 Workspace 时应用会突然退出的问题。

### 右键 Tab 批量关闭

![在 Tab 上右键，选择要关闭哪些 Tab](mock:tab-menu)

在 Tab 上右键，可以选择「关闭 Tab」「关闭其他 Tab」「关闭左侧 Tab」「关闭右侧 Tab」或「关闭所有 Tab」，没有可关的项会置灰。一次关好几个时，只要其中有终端还在运行，只会确认一次，不会每个 Tab 都问一遍。关掉的 Codex / Claude Code 会话之后还能从侧栏恢复。

### 跳过权限启动 Claude Code

![项目的「+」菜单里多了「Claude Code（跳过权限）」](mock:skip-permissions)

凡是能新建会话的地方（「+」菜单、项目 / Worktree / 终端的右键菜单、命令面板 `⌘K`），Claude Code 下面都多了一项「Claude Code（跳过权限）」。它不再询问权限，直接执行命令和修改文件，适合放手让 agent 自己干的任务。这个设置只对本次启动有效：重启 Seperate 后恢复的会话会重新询问权限。

#### 修复

- 点击系统通知、回答 agent 的提问或者切换 Workspace 时，Seperate 有时会突然退出；现在不会了
- 点击另一个 Workspace 里会话的通知后，键盘焦点有时不在那个终端上；现在跳过去就能直接打字
