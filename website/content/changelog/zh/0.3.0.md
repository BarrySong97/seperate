title: Seperate 支持英文了
---

Seperate 以前只有中文界面。从这个版本开始，整个应用都有中文和英文两种语言，默认跟随你 Mac 的系统语言，也可以自己选。

### 中文还是英文，你来选

![Seperate 菜单 › 语言](mock:language-menu)

菜单、对话框、侧栏、收件箱、命令面板和系统通知都有了英文版。默认情况下，Mac 的首选语言是中文就显示中文，否则显示英文。想自己选的话，打开 **Seperate › 语言**，选「跟随系统」「中文」或「English」。Seperate 会提示重启以生效；你的项目、Workspace 和会话名称都原样保留。

### 安装器也跟着你的语言

磁盘映像里的安装器在中文系统上显示为「安装 Seperate」，在英文系统上是「Install Seperate」，安装窗口跟随系统语言，背景上的说明也是中英双语。

#### 改进

- Claude Code 和 Codex 发来的通知（提问、等你确认的计划）和应用用同一种语言
- 英文界面里的时间写成习惯的样子："5m"、"3h"、"yesterday"、"Sep 12"
- 官网也有英文版了，中文版在 seperate.vercel.app/zh
