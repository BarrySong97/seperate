Claude Code 和 Codex 现在可以自己操控 Seperate：在旁边新开一栏跑另一个 Agent、给它派活、等它回话、做完关掉，整个过程都在你眼前。在 Seperate 外面开的会话一秒左右就会出现，每个会话也终于都有了认得出的名字。

### Agent 可以开启、指挥、等待其他 Agent

![Claude Code 和 Codex 通过 seperate 命令操控 Seperate](mock:cli-control)

Seperate 里的每个终端现在都有一个 `seperate` 命令，Claude Code 和 Codex 启动时也会被告知有这个命令。你跟 Claude 说「让 Codex 修一下这个失败的测试，告诉我它改了什么」，它就可以：

- 在自己旁边新开一栏启动 Codex，把任务作为第一句话发给它（你的键盘焦点不会被抢走）
- 等 Codex 这一轮做完或者有问题要问，读它的回复或者终端内容
- 回答它的问题、按键选选项，最后把会话关掉

`seperate list` 会列出所有 Workspace、项目、Worktree 和会话以及它们的状态。Agent 也可以在已有的 Worktree 里开会话，或者先新建一个 Worktree。Agent 开了会话或往会话里输入时，那一栏的顶部会显示「由 … 打开」或「… 输入」和时间；你自己在里面打字后这行就消失。Seperate 外面的脚本和机器人也能用，路径是 `/Applications/Seperate.app/Contents/MacOS/seperate-cli`。运行 `seperate --help` 可以看到全部用法。

### 在别处开的会话马上出现

在 Seperate 外面启动 Claude Code 或 Codex（别的终端、飞书机器人、Agent SDK），会话现在一秒左右就会出现在侧栏里，不用再等最多一分钟。切回 Seperate 时也会马上再查一次。

### 会话有了真正的名字

会话现在使用 Claude Code 给对话起的标题，对话进行中标题变了也会跟着更新。没有标题的 Codex 会话，用你问它的第一句话命名。从 Agent SDK 或聊天机器人开的会话也有了正常的名字，不再是「Claude 会话」「Codex 会话」。

#### 改进

- 新开的 Tab 和分屏沿用你用 ⌘+ / ⌘- 调好的字号
- 在别处继续聊的会话会重新排到所在 Worktree 的最上面

#### 修复

- 在一个原本没有会话的 Worktree 里开了新会话，它会被收在折叠的行里看不到；现在新出现的项目和 Worktree 行会自动展开
- 项目从一个 Worktree 变成多个时，原来的会话会被折叠起来；现在会一直显示
- 在 Seperate 里开的会话重启后还叫「Claude Code 6」这类临时名字；现在显示对话的标题
